• Realization of the compiler for programming language MicroJava.

• The compiler enables translation of syntactically and semantically correct MicroJava programs into a MicroJava bytecode that is executed on a virtual Microjava machine.

• The compiler for MicroJava has four basic functionalities: lexical analysis, syntax analysis, semantic analysis, and code generation.

• Project for course Compiler Construction 1, School of Electrical Engineering, University of Belgrade
